# Исполнители задач — 0.4.0

Один необязательный исполнитель на задачу, локальный справочник имён без аккаунтов. Имена нормализуются NFC, последовательности пробелов сворачиваются; ограничение — 100 Unicode codepoints. Уникальный ключ формируется NFKC + full Unicode case folding + NFKC. Архивные записи участвуют в проверке уникальности. Переименование сохраняет UUID; новых назначений на архивного исполнителя нет, прежние назначения можно сохранить или снять.

## Хранение

Схема SQLCipher 4:

- `planner_assignees`: UUID, имя, уникальный нормализованный ключ, архив, ревизия и даты.
- `planner_task_assignees`: одна строка на назначенную задачу, внешние ключи и индекс исполнителя. Поле `assigneeId` присутствует в API, но не дублируется в JSON задачи.
- `planner_task_events`: назначение/смена/снятие, завершение/возобновление и начальное состояние при миграции. История содержит ревизию задачи, UTC, причину, идентификаторы и снимки имён. Миграция не придумывает даты событий до обновления.

Типизированные команды `assignees` / `assigneeChange`. Создание повторяемо по UUID; редактирование справочника проверяет ревизию. Назначение и история записываются в транзакции задачи. Черновик хранит `assigneeId`, но не создаёт события. Изменение признака завершающей стадии и удаление стадии также фиксируют изменение завершённости с причиной `stageSettings`. Архив/корзина сами по себе не считаются завершением.

Миграция 3 → 4 включена в цепочку старых версий. До её начала создаётся отдельная зашифрованная копия и проверяется чтением всех ZIP-элементов; изменения схемы проходят одной транзакцией. Восстановление копий проверяет справочник, ссылки назначений и черновика, типы событий, даты, ревизии и снимки исполнителей. Пароль и recovery key прежние.

## Интерфейс

Широкая строка: название, исполнитель, дедлайн. При ширине до 900 px название занимает отдельную строку; до 600 px поля располагаются вертикально. Карточка показывает имя под описанием, длинное имя сокращается с подсказкой.

Общий `TaskDialog` используется из Планера и дневника. Кнопка «+» ждёт импорта вложений и сохранения черновика, затем открывает вложенные настройки с фокусом на имени. При успехе новый исполнитель выбирается в черновике; закрытие без создания сохраняет прежний выбор. Созданная запись справочника остаётся после отмены задачи. Несохранённое имя требует подтверждения закрытия. Во время записи справочника закрытие вложенного окна заблокировано. Блокировка хранилища очищает оба окна; запоздалые ответы не возвращают содержимое. В режиме просмотра выбор отключён, кнопка «+» скрыта.

Стадии по-прежнему нельзя менять при открытом черновике; управление исполнителями от этого ограничения независимо. Список сортируется по русскому алфавиту, без ручной перестановки. При конфликте ревизий показывается ошибка и обновляется список; пользователь повторно выбирает актуальную строку для редактирования.

## Проверки 2026-10-11

- Rust: 31 тест, включая Unicode 100/101, case folding, повтор создания, ревизии, архив, откат задачи и назначения при ошибке записи истории, снимки имён, завершение/возобновление через настройки стадий, миграцию 3 → 4, восстановление копии с черновиком и отсутствие открытых контрольных строк.
- Vitest: 3 теста очереди сохранения/настроек.
- Playwright/Edge: 32 теста, включая два новых сценария исполнителей, вложенное окно, отмену, сохранность описания и дедлайна, переименование/архив и drag-and-drop карточки. Проверены размеры 1280×840 и 580×840, сделаны и просмотрены снимки экрана. Browser plugin not available — использован существующий Playwright проекта.
- Нативный `scripts/native-assignees.mjs`: отдельный профиль, создание из окна задачи, сохранение/принудительный перезапуск, зашифрованный черновик, блокировка с открытыми настройками, архивный исполнитель. WebView2, фактический DPI 125%. Личный дневник не использовался.

Результаты общей нативной регрессии и контрольная сумма установщика фиксируются в `ACCEPTANCE.md` и `releases/SHA256SUMS.txt`. Нативная автоматизация запускает собранный Windows executable с тестовым профилем; она не подменяет ручную проверку установщика и масштабов Windows 100/150/200%. Отчёты по исполнителям и историческая статистика до момента миграции отсутствуют по плану.
