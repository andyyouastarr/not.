# Связанные задачи

`task_links.rs` хранит fragment/entry/task/operation UUID, наличие источника и отмену создания в зашифрованной базе. `createLinkedTask` сохраняет задачу, документ, ревизию, FTS и связь одной транзакцией. Повтор operation UUID возвращает существующую задачу. Черновик Планера не меняется. Обычное сохранение дневника проверяет принадлежность отметок и синхронизирует источники в той же транзакции. Удалённый источник сохраняет строку связи для восстановления через историю.

Миграция 1/2 → 3 выполняется после снимка SQLCipher и проверки ZIP CRC. Обе ступени миграции из версии 1 находятся в одной транзакции. Восстановление резервной копии проверяет документы, ссылки на задачи и принадлежность фрагментов. В HTML-экспорте служебные отметки игнорируются.

`context_menu.rs` дополняет стандартную коллекцию WebView2 после команды `selectAll`. Deferral позволяет запросить контекст редактора без блокировки UI-потока. В нативный мост передаются только подпись действия, enabled и случайный токен; текст выделения остаётся в редакторе. Версия Tauri ограничена текущей minor-веткой из-за прямого использования WebView2 API. Диагностика состава меню включается только в debug-сборке с отдельным тестовым профилем.

`DiaryTaskMenu.tsx` фиксирует bookmark выделения, отображает позиции после транзакций и инвалидирует контекст при размонтировании/блокировке. `taskLinks.ts` задаёт нерасширяемую по границам отметку и доступные с клавиатуры декорации. Полное удаление/замена удерживает транзакцию до подтверждения; отмена не меняет документ. Отметки не сериализуются в HTML буфера обмена. Перенос блока использует исходный узел, сохраняя метаданные. Отмена создания исключает повторное появление отменённого идентификатора из истории текущего редактора.

`useLinkedTasks.tsx` связывает очередь сохранения, импорт вложений, атомарные команды, уведомление и общий `TaskDialog`. На время фиксации редактирование блокируется. Epoch хранилища отбрасывает запоздалый ответ после блокировки. Чужой черновик открывает задачу только для просмотра; собственный черновик можно продолжить.

Проверки: `tests/linked-tasks.spec.ts`, Rust-тесты `task_links::tests`, нативный сценарий `scripts/native-task-links.mjs`. Последний использует отдельный профиль в `artifacts` и не открывает личный дневник. Точные результаты и непроверенные сценарии перечислены в `ACCEPTANCE.md`.
