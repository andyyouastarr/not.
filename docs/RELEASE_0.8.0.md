# not. studio 0.8.0 — PDF A4

28 ноября 2026.

## Что изменилось

Кнопка «Скачать PDF» справа в панели дневника и задачи открывает Windows
«Сохранить как». Экспортируется текущий текст и реквизиты, включая несохранённые
правки. Экспорт не создаёт задачу и не меняет документ или историю редактирования.

Формат: A4, поля 18 мм, текст 11 pt, белый фон, номера страниц. Сохраняются
изображения, их стороны и относительные размеры, обтекание, таблицы, списки,
чек-листы, хайлайты, ссылки и Timestamp. Переносы адаптируются к A4; совпадение
с экранными строками не предполагается. Вложения представлены именем и размером.

Изображения с подписью не разрезаются. Группы обтекания, помещающиеся на странице,
переносятся вместе; слишком длинный текст продолжает поток на следующей странице.
Большое изображение уменьшается пропорционально. При недостатке места для текста
изображение занимает отдельную строку с сохранением стороны. Заголовки таблиц
повторяются на следующих страницах.

## Устройство и защита

Отдельное статическое представление строится из JSON без изменения ProseMirror.
Шрифты и изображения ожидаются до печати, проверяются геометрия и неизвестные узлы.
WebView2 PrintToPdfStream создаёт выделяемый текст. Rust проверяет базовую структуру
и размеры страниц; файл записывается атомарно в выбранной пользователем папке.
Открытый временный PDF существует только в целевой папке до атомарной замены.
HTML и изображения экспортного представления остаются в памяти.

Блокировка инвалидирует операцию. Запоздалый результат не может опубликовать файл.
Таймаут — 60 секунд, ограничение потока — 128 МБ. Миграции БД нет.
Для белых полей WebView2 временно получает белый backing color, затем исходный
цвет восстанавливается; тема и оформление интерфейса не переключаются.

## Проверки

- TypeScript + production Vite build: успешно (сохраняется предупреждение о размере JS bundle).
- Vitest: 11 проверок успешно.
- Rust: 43 теста успешно; финальный Clippy без предупреждений.
- Полный Playwright: 52 сценария успешно; затем добавлены ещё 2 PDF-сценария,
  отдельный финальный прогон 5 PDF-тестов успешен.
- Проверка PyMuPDF двух восьмистраничных документов: A4, все 40 контрольных абзацев
  по одному, конечный текст, изображение внутри страницы, белые поля.
- Нативный WebView2, отдельное хранилище: экспорт несохранённой задачи с изображением
  справа (4 страницы), дневника (1 страница), неизменность документа, отсутствие
  созданной карточки, отклонение операции после блокировки. PyMuPDF подтвердил
  весь контрольный текст, размер A4 и белые поля. Отрисованные страницы просмотрены.
- Регрессия ввода названия: 0 обновлений редактора описания, редактор и undo сохранены.

Воспроизведение: `node scripts/native-pdf-080.mjs`; затем
`python -X utf8 scripts/verify-pdf.py <task.pdf> <diary.pdf>` (требуется PyMuPDF).
Нативный скрипт использует только новый `NOT_STUDIO_TEST_DATA_DIR`; выбор пути
автоматизирован исключительно в debug-сборке. Личное хранилище не использовалось.

## Ограничения проверки

Ручной выбор пути в стандартном диалоге, установка поверх существующей версии,
физические масштабы Windows 150/200%, отключение диска во время записи и зависший
драйвер печати не проверялись. Использована нативная тестовая сборка, а не ручной
прогон установленного релиза. Автоматическая проверка PDF не доказывает идеальную
пагинацию всех возможных документов: особо сложные таблицы с объединёнными ячейками
и несколько соседних больших изображений требуют дополнительной ручной оценки.
