# Timestamp-разделитель — 0.6.1

В редактируемом описании задачи нажмите ПКМ → **Timestamp разделитель**. В текстовом меню команда следует после «Выбрать все». У изображений WebView2 может не предоставлять этот пункт; тогда команда добавляется в конец существующего меню. Стандартные операции остаются на месте. Поддерживается вызов меню через Shift+F10.

Дата `ДД.ММ.ГГГГ` фиксируется по местному времени устройства в момент выполнения команды. Слева — подпись системным шрифтом 11 px, справа — тонкая линия. Цвета соответствуют теме; блок очищает обтекание изображений. Дата не редактируется и не обновляется при повторном открытии.

Разделитель вставляется после блока под указателем. Если указатель внутри выделения, используется последний выделенный блок. В списках, цитатах и таблицах используется внешний блок. При клавиатурном вызове используется выделение/курсор. Следующий пустой абзац используется повторно либо создаётся новый; фокус сразу возвращается в него. Текст не заменяется.

Backspace в начале следующего абзаца выделяет разделитель, повторный Backspace удаляет. Delete удаляет выбранный блок. Вставка — один шаг undo; дата сохраняется при undo/redo, перестановке и копировании. Пункт недоступен в режиме просмотра, вкладке истории и полях задачи. Закрытие/блокировка/смена вкладки инвалидируют прежнюю команду; изменение документа при открытом меню также отменяет устаревший контекст.

## Данные и совместимость

JSON-узел: `{"type":"timestampDivider","attrs":{"date":"2026-11-01"}}`. Он поддерживается общим редактором, в том числе при вставке скопированного содержимого в дневник; команда создания предоставлена только в задаче. Rust проверяет календарную дату и отсутствие вложенного содержимого у этого атомарного блока. Текстовое представление, поиск дневника, превью задачи и буфер получают дату; HTML сохраняет семантический блок с `data-timestamp-date` и `<time>`. Экспорт имеет собственные нейтральные цвета, не зависит от текущей темы.

Разделитель сохраняется обычным механизмом задачи и зашифрованного черновика. Сохранение изменённого описания создаёт стандартное событие `edited` с полем `document`; отдельного типа события нет.

Схема 5 → 6 не меняет таблицы или существующие документы. До изменения создаётся отдельная зашифрованная копия с CRC-проверкой компонентов архива. Предыдущие миграции не повторяются. Версия 0.6.0 поддерживает только схемы до 5 и отклонит схему 6; для возврата нужна копия до обновления. Пароль и recovery key остаются прежними.

## Проверки и ограничения

Автоматические проверки — `TimestampDivider.test.ts`, `tests/timestamp.spec.ts`, Rust-тест `timestamp_roundtrip_migration_and_validation`, `scripts/native-timestamp.mjs`. Нативная проверка запускает embedded frontend в Windows/WebView2 с отдельным синтетическим хранилищем; личное хранилище не используется.

В нативной автоматизации проверяются настоящая коллекция меню и позиция пункта, затем вызывается тот же обработчик команды через JS-мост. Это не физическое нажатие пункта мышью. Ручная установка NSIS, Windows DPI 100/150/200% и реальная смена часового пояса Windows отдельно не проверены. Фактический масштаб нативной среды — 125%. Сохранённая дата проверяется после перезапуска; перевод часов вперёд проверяется браузерной автоматизацией.
