# not. studio 0.1.3 — Windows x64

[Скачать установщик 0.1.3](https://github.com/andyyouastarr/not./releases/download/v0.1.3/not-studio-0.1.3-windows-x64-setup.exe). Локальная копия: `not-studio-0.1.3-windows-x64-setup.exe`. Контрольная сумма — в `SHA256SUMS.txt`.

В 0.1.3 добавлены независимое изменение ширины клавиатуры боковыми границами, закрытие настроек кликом по фону и маркер текста с четырьмя приглушёнными цветами. Выделение сохраняется в дневнике, резервных копиях и HTML-экспорте. Повторный выбор цвета снимает выделение; доступны ластик и undo/redo. Для записей с маркером требуется версия 0.1.3 или новее.

В этой папке автоматически сохраняются два последних установщика. Удаление старых версий выполняется только после успешной сборки и проверки контрольной суммы нового файла.

Кнопка клавиатуры рядом с режимом фокуса открывает панель-подсказку. Она ничего не вводит, автоматически показывает стандартную русскую или US раскладку Windows, поддерживает изменение высоты за верхнюю границу и сохраняет размер и видимость. Панель работает и в режиме фокуса, не перекрывает документ. Для нестандартных раскладок выводится сообщение.

Перед обновлением создайте резервную копию, сохраните запись и закройте программу. В установщике выберите «Не удалять». Дневник и его пароль сохраняются, миграция базы не требуется. Сборка не подписана сертификатом издателя. Проверки выполнены на Windows 10 с отдельным тестовым дневником; подробности — в [приёмке](../docs/ACCEPTANCE.md).

## Предыдущая версия 0.1.1

[Скачать установщик из GitHub Releases](https://github.com/andyyouastarr/not./releases/download/v0.1.1/not-studio-0.1.1-windows-x64-setup.exe).

Перед обновлением создайте резервную копию. На экране «Уже установлено» выберите «Не удалять». Если запускаете удаление старой версии, не отмечайте удаление данных приложения: этот пункт удаляет локальный дневник.

Сохраните запись и закройте текущую программу, затем запустите `not-studio-0.1.1-windows-x64-setup.exe`. При обновлении откройте дневник прежним паролем. Для нового хранилища создайте пароль и сохраните ключ восстановления отдельно.

Сборка от 12 сентября 2026. Установщик: 4 887 581 байт. Контрольная сумма — в `SHA256SUMS.txt`.

Исправлено обрезание вложений после 64 КиБ; добавлены изменение размера картинки за угол, перетаскивание и автоматическое обтекание текстом. Размер и положение сохраняются, поддерживаются undo/redo и HTML-экспорт. Старые неполные вложения нужно добавить заново из оригиналов; у повреждённых картинок есть кнопка замены.

Это личная сборка без сертификата подписи кода. Тесты выполнены на Windows 10 Pro 19045; приёмка Windows 11 и двухнедельное использование ещё не завершены. Мастер обновления не запускался, поскольку пользовательский дневник открыт. Нативные проверки выполнены в отдельном профиле со встроенным интерфейсом.

Полные результаты и ограничения: [приёмка](../docs/ACCEPTANCE.md). Инструкция и исходный код: [README](../README.md).
